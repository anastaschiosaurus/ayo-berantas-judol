# How to Use AyoBerantasJudol Extension

## Installation

1. Download the latest version of `berantas.ext` from [this link](https://download-directory.github.io/?url=https://github.com/anastaschiosaurus/ayo-berantas-judol/tree/main/berantas.ext).
2. Unzip the downloaded folder.
<img width="1268" height="563" alt="image" src="https://github.com/user-attachments/assets/0b94b2fb-f1fd-4f1b-bd01-7a9739a50836" />

4. Open Google Chrome and navigate to `chrome://extensions/`.
5. Turn on **Developer mode**.
<img width="1356" height="451" alt="image" src="https://github.com/user-attachments/assets/5216fda1-f4c0-4eb8-8aa5-95efa9f6ed4e" />

6. Click **Load unpacked**.
<img width="1354" height="451" alt="image" src="https://github.com/user-attachments/assets/8d5ee6c5-7ae2-4f33-8014-88fc5f4215e1" />

7. Select the unzipped extension folder.
<img width="1204" height="852" alt="image" src="https://github.com/user-attachments/assets/3be296e7-687c-42de-befb-1a50b5f05f41" />

8. Activate the extension.
<img width="1090" height="638" alt="image" src="https://github.com/user-attachments/assets/bd2ff253-c622-465c-a949-20af963ab640" />
